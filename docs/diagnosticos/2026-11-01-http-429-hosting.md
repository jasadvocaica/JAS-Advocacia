## Evidências
Juliana confirmou o endereço `https://app.julianaaraujoadvocacia.com/` e informou que acessa o hPanel, sem aviso de recursos.

01/11/2026, horário de Cuiabá:
- 16:36: GET `/` → HTTP 429, corpo vazio, content-length 0. Headers de origem identificam `platform: hostinger`, `panel: hpanel` e `x-hcdn-request-id: ffef66cce652308ecc8bd49105c6ceb3-phx-edge14`.
- 16:38: HEAD `/index.html` → HTTP 429, content-length 0, mesmos identificadores de plataforma, request ID `904280fc6539c8d5191b4a4c60aa9f4b-phx-edge11`.

Foram duas consultas iniciais de diagnóstico, sem autenticação, cookies ou repetição automática. O endereço IP remoto visto pelo curl é o proxy do ambiente, não o IP de origem do site, e não foi usado para atribuir a falha.

O HTML/JavaScript não é servido nessa resposta; portanto a página não chega a iniciar React ou suas consultas Supabase. Isso localiza a indisponibilidade na entrega HTTP da hospedagem/CDN, mas não identifica a regra exata. Pode haver restrição de tráfego ou de recursos na infraestrutura; só os logs do provedor confirmam a causa. Ausência de aviso no painel não resolve essa incerteza.

O .htaccess versionado possui o redirecionamento SPA usual e exclui index.html. Não foi encontrada regra 429 nele. Não há evidência para alterar o banco, o orçamento de tokens, suspender agentes ou mudar esse arquivo como correção desta resposta.
